第 01 章

五分钟快速开始

准备一部可连接 Wi-Fi 的手机或电脑、可访问互联网的 2.4 GHz 无线网络，并为设备接通电源。

1开机接通电源并打开设备电源
2连热点连接 Xiaozhi-XXXX
3配 Wi-Fi访问 192.168.4.1
4激活在 xiaozhi.me 添加设备
5开始对话说“你好喵伴”
  1. 开机：接通电源并打开设备电源，等待屏幕亮起。首次启动可能需要稍长时间加载资源。
  2. 连接设备热点：在手机 Wi-Fi 列表中选择名称类似 Xiaozhi-XXXX 的热点。
  3. 填写家庭 Wi-Fi：浏览器访问 http://192.168.4.1，选择家庭网络并输入密码。
  4. 完成激活：设备联网后会播报并显示激活提示。登录 xiaozhi.me，在控制台添加设备并输入激活码。
  5. 开始使用：设备显示“待命”后，说“你好小智”或“你好喵伴”，听到提示音或看到“聆听中”后再说出问题。
请勿过早断电 初次启动、下载资源或升级过程中，请保持供电稳定。若屏幕显示正在升级或正在下载资源，不要关闭电源。

第 03 章

连接 Wi-Fi

首次开机没有已保存的网络时，设备会自动进入热点配网模式，并播报热点名称与配置地址。

  1. 打开手机或电脑的 Wi-Fi 设置，找到名称类似 Xiaozhi-XXXX 的设备热点并连接。末尾字符因设备而异。
  2. 如果系统提示“此网络无法访问互联网”，请选择仍然连接或保持连接。
  3. 打开浏览器访问 http://192.168.4.1。部分手机会自动弹出配网页。
  4. 等待页面扫描附近网络，选择要连接的 2.4 GHz Wi-Fi，输入正确密码并提交。
  5. 设备尝试连接期间不要关闭页面或断电。连接成功后设备热点会关闭，手机可恢复到原来的网络。
设备热点Xiaozhi-XXXX
配置页面192.168.4.1
家庭网络选择 SSID 并输入密码
连接成功设备进入激活或待命

重新配网

需要更换路由器或 Wi-Fi 密码时，可在设备刚启动时轻触屏幕或单击实体按键进入配网。设备尝试连接已保存网络超过约 60 秒仍未成功时，也会自动进入配网模式。

网络要求ESP32-S3 使用 2.4 GHz Wi-Fi。若路由器将 2.4 GHz 与 5 GHz 合并为同一名称，通常可以连接；遇到失败时，可暂时为 2.4 GHz 单独设置网络名称再配网。

配网注意事项

  • 设备最多可保存多组网络，通常优先尝试最近成功使用的网络。
  • 热点名称和密码区分大小写；企业认证、网页认证或需短信登录的公共 Wi-Fi 可能无法直接使用。
  • 访问配置页面时建议暂时关闭手机蜂窝数据或“智能切换网络”，避免浏览器绕过设备热点。
第 04 章

激活设备

设备连接互联网后会自动检查激活状态。未激活时，屏幕和语音会给出激活码或操作提示。

设备联网等待激活提示
登录平台访问 xiaozhi.me
添加设备输入屏幕显示的激活码
激活完成设备自动进入待命
  1. 在手机或电脑浏览器访问 https://xiaozhi.me，注册并登录个人账号。
  2. 打开控制台中的设备管理或添加设备页面。平台界面名称可能随版本调整。
  3. 按设备屏幕和语音提示输入激活码，确认绑定到当前账号。
  4. 保持设备联网，等待设备自动确认。屏幕进入“待命”即表示可以使用。
激活码会更新激活请求可能有有效时间。若操作过久导致激活码失效，请等待设备重新提示，或说唤醒词让设备再次检查激活状态，再使用新的提示完成绑定。

第 05 章

语音对话

开始一次对话

  1. 设备显示“待命”时，说“你好小智”或“你好喵伴”。
  2. 听到提示音或看到“聆听中...”后，用自然语速说出问题或指令。
  3. 设备识别语音并连接服务，随后显示字幕、表情并播放语音回答。
  4. 需要中断时，可再次说唤醒词，或轻触屏幕/单击实体按键切换对话状态。

提升识别效果

  • 在正常室内距离说话，避免紧贴麦克风大声喊叫。
  • 不要遮挡拾音孔；电视、音乐或多人同时说话会降低识别准确率。
  • 看到“聆听中...”后再说完整指令。较长问题可用自然停顿，但不要停顿过久。
  • 云端知识、天气和扩展能力取决于账号中的智能体及服务配置，实际回答可能不同。
第 06 章

播放本地音乐

喵伴可以扫描 SD 卡中的 MP3 文件，通过语音点歌，并在屏幕显示歌名、播放时间、进度和同步歌词。

准备音乐文件

  1. 准备可正常播放的 MP3 文件。当前固件的本地音乐功能不以 WAV、FLAC、AAC 等格式作为播放入口。
  2. 将音乐放入 SD 卡的 /music 文件夹。固件也兼容扫描 SD 卡根目录，但推荐统一使用 /music。
  3. 需要歌词时，将 LRC 文件与歌曲放在同一目录，并使用相同的主文件名，例如 晴天.mp3 与 晴天.lrc。
  4. 插入 SD 卡后说“刷新音乐库”，或通过媒体管理页面上传，设备会重新扫描曲库。

歌词说明

  • 支持常见 LRC 时间标签，并可读取 UTF-8、UTF-16 以及常见 GBK/CP936 中文歌词。
  • LRC 文件最大 512 KiB；建议使用标准时间轴并避免单行过长。
  • 歌词不同步通常由 LRC 时间轴或偏移量造成，与 MP3 文件名无关。
第 07 章

媒体管理

无需拔出 SD 卡，可以在同一局域网内通过手机或电脑上传、重命名和删除壁纸、MP3 音乐及 LRC 歌词。

  1. 确认喵伴已连接 Wi-Fi，且手机或电脑与设备处于同一局域网。
  2. 对设备说“打开媒体管理页面”。
  3. 扫描屏幕二维码，或在浏览器输入屏幕显示的地址，形式通常为 http://设备IP:8080。
  4. 选择“壁纸”或“音乐”，选取文件后上传。上传完成后设备会刷新对应媒体库。
  5. 完成管理后可说“关闭媒体管理页面”；若不操作，页面约 30 分钟后自动关闭。

第 08 章

壁纸桌面

在 Emote 界面固件中，设备待命一段时间后会进入壁纸桌面，显示日期、时间以及已缓存的城市天气。

自动显示与轮播

  • 设备保持待命且没有播放音乐时，约 30 秒后自动显示壁纸桌面。
  • 壁纸显示后约每 30 秒切换一张，并带有淡入过渡。
  • 开始对话、播放音乐、显示通知或打开媒体二维码时，壁纸会自动隐藏。
  • 没有自定义壁纸时使用内置晨曦、白昼和夜晚壁纸。

打开管理打开媒体管理页面。

城市和最近一次天气信息会保存在设备中。天气内容由联网服务返回并写入壁纸缓存；离线时可能继续显示上一次结果，并不代表实时天气。

使用自定义壁纸

  1. 准备 JPG 或 JPEG 图片。建议使用接近正方形的构图，并将主要内容放在画面中央，以适应圆形屏幕。
  2. 通过媒体管理页面上传到“壁纸”，或放入 SD 卡 /wallpapers 文件夹。
  3. 上传成功后设备自动刷新；手动放入 SD 卡时，可说“刷新壁纸”。
  4. 只要扫描到有效的自定义壁纸，轮播会优先使用这些图片；若没有有效文件，则回退到内置壁纸。
构图建议屏幕为 360×360 圆形显示区域。建议使用 1:1 图片，避免把人物面部、文字或标志放在四角；图片无需预先裁成圆形。
第 09 章

其他功能

音量与亮度

可直接用语音设置 0～100 的音量或屏幕亮度，例如“把音量调到 30”“屏幕亮一点”“亮度调到 50”。设备会保存部分设置，后续开机继续使用。

保护听力与扬声器近距离使用时不建议长时间保持高音量。出现明显破音时请立即降低音量。

电量和充电提示

  • 状态区域会显示电量和充电状态；也可以问“还剩多少电”。
  • 接入充电电源时，设备会显示充电相关表情反馈。
  • 电量下降到约 10% 和 5% 时会触发低电量表情提示，并可能间隔重复提醒。
  • 电量过低时应及时充电，避免在升级、写入 SD 卡或上传文件过程中断电。

第 10 章

常见问题

找不到 Xiaozhi-XXXX 热点

确认设备已开机并处于配网模式。可重新上电，在启动阶段轻触屏幕或单击实体按键；手机刷新 Wi-Fi 列表并靠近设备。若设备正在连接已保存网络，请等待约 60 秒自动进入配网。

连接热点后打不开 192.168.4.1

确认手机仍连接设备热点；关闭蜂窝数据、VPN 和“智能切换网络”，手动输入完整地址 http://192.168.4.1，不要使用 HTTPS。必要时更换浏览器。

Wi-Fi 一直连接失败

确认选择 2.4 GHz 网络、密码和大小写正确，并靠近路由器。避免使用需网页认证或企业账号认证的网络。修改路由器密码后需要重新配网。

已联网但没有激活码

检查互联网是否可用，等待设备完成时间同步和服务连接。可说“你好喵伴”重新触发激活检查，或重启设备再试。

说唤醒词没有反应

确认设备显示“待命”、音量不是 0，并避开强噪声。靠近设备清晰地说“你好小智”或“你好喵伴”，不要遮挡麦克风孔。也可轻触屏幕开始对话。

SD 卡不可用或歌曲列表为空

停止音乐并重新插入 SD 卡后重启。确认文件为 MP3，优先放在 /music 目录。若仍无效，备份文件后使用常见 FAT 文件系统重新格式化 SD 卡。

能够播放歌曲但不显示歌词

确认 MP3 与 LRC 位于同一目录、主文件名完全相同，且 LRC 小于 512 KiB。检查 LRC 是否包含标准时间标签；随后停止播放并刷新音乐库。

壁纸没有自动出现

壁纸只在 Emote 固件的空闲状态显示。停止音乐和对话，等待约 30 秒；检查 JPG/JPEG 文件是否小于 2 MiB、尺寸不超过 1024×1024，然后说“刷新壁纸”。

媒体管理页面打不开

确认手机与设备处于同一 Wi-Fi，重新说“打开媒体管理页面”获取最新地址。页面端口通常为 8080，路由器的访客网络或 AP 隔离功能可能阻止设备互访。

无法上传、删除或重命名音乐

先说“停止音乐”。音乐处于播放或暂停状态时，设备会保护正在使用的文件并拒绝修改。还要确认文件扩展名和大小符合限制，且目标文件名未被占用。

第 11 章

安全与维护

  • 使用规格匹配、质量可靠的供电设备和线缆，避免接口松动导致反复重启。
  • 设备不防水。远离雨水、饮料、高湿、油烟、金属碎屑和高温环境。
  • 不要堵塞扬声器或麦克风孔，不要用尖锐物体按压屏幕或触控区域。
  • 不要猛烈摇晃、抛掷、拆解或挤压设备及电池。
  • 上传文件、更新固件或设备写入 SD 卡时，不要拔卡或断电。
  • 需要取出 SD 卡时，先停止音乐并关闭媒体管理页面，建议关机后再操作。
  • 激活账号和设备可能关联个人配置。转让设备前，请在服务平台解除绑定并清理个人数据。
  • 语音请求可能发送到联网服务处理。请勿在不可信环境中说出密码、验证码等敏感信息。

日常清洁

先断开电源，再用柔软、微湿且不滴水的布擦拭外壳和屏幕。不要将清洁剂直接喷到设备上，不要使用酒精、强溶剂或研磨材料。

异常处理

如出现电池鼓胀、异常发热、异味、冒烟或外壳损坏，应立即停止使用并断开电源，远离可燃物，联系有资质的人员处理。
